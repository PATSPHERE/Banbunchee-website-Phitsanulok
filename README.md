## Editing

- Main page structure and content: `index.html`
- Colours, spacing and responsive layout: `css/style.css`
- Thai/English text, menu behaviour and prototype SVG artwork: `js/main.js`
- Project decisions and items to verify: `docs/`

## Local preview

```bash
python -m http.server 8000
```

Then open `http://localhost:8000`.

## GitHub Pages

In repository settings, open **Pages**, choose **Deploy from a branch**, then select `main` and `/ (root)`.
